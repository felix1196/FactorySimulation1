# FactorySimulation1

Simulación animada de una línea de producción (creación, ensamble, pruebas, reparación, scrap y empacado). Abre `index.html` en el navegador.

- Idiomas: Español / English
- Temas: oscuro / claro
- Paro de línea por exceso de scrap con autorización por credenciales (por defecto supervisor / 1234)
